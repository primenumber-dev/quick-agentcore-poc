# セッション再開用プロンプト(コピペ用)

新しいセッションを開始する際、最初のメッセージとして以下をそのまま貼り付ける。

---

```
このプロジェクト(quick-mcp-poc: AgentCore Runtime移行検証)の作業を再開します。

まず以下を読んで、現状を把握してから着手してください。
1. CLAUDE.md
2. docs/00-handoff.md(前回セッションの状況・未着手事項・既知のはまりどころ)
3. docs/README.md(技術ドキュメント一覧)

その上で、以下を確認・実施してください。
- 2つのAWSプロファイル(quick-agentcore-poc, quick-agentcore-poc-playground)のSSOトークンが有効か確認し、失効していれば再ログインを案内する
- quick-agentcore-poc(本番相当・実クライアントデータあり)への書き込みは引き続き禁止。検証はquick-agentcore-poc-playgroundで行う
- ローカルのDocker/LocalStackが起動したままかを確認する

準備ができたら、現在の状況(完了済み/未着手の項目)を簡潔に報告し、次に何をするか私の指示を待ってください。作業中に新しく分かった詰まった点や決定事項は、都度docs/00-handoff.mdに反映してください。
```

---

## メンテナンスの指針

- `docs/00-handoff.md`は生きたドキュメント。セッションをまたぐたびに状況(完了/未着手、作成済みAWSリソース、はまりどころ)を追記・更新する。
- 上記プロンプト自体は極力変更しない(プロジェクトが進んでも再利用できるよう、詳細は`00-handoff.md`側に持たせる設計)。
